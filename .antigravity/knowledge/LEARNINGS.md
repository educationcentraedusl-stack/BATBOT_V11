# AUTONOMIC MEMORY JOURNAL (THE BRAIN)

## Core Architectural Rules (Learned)
* **Financial Fallbacks:** Zero silent financial fallbacks permitted. Never use `.catch(() => null)` in trade execution blocks.
* **Engine State Persistence:** NEVER write placeholder stubs for engine initializations. Core engines must persist in global static state (`lazy_static` / `RwLock`) rather than dropping scope-local variables.
* **Buffer Bounds Safety:** ALWAYS clamp loop counts in zero-copy array operations against provided buffer lengths (`Math.min(requested, array.length)`).
* **Atomic Test Fidelity:** Never mock atomic hardware barriers with non-atomic assignments. Test suites must match production atomic 64-bit store mechanics 1:1.

## Structural Learnings & Edge Cases
* **IPC Memory Sync:** V8 Garbage Collector pauses disrupt Rust IPC if buffers are allocated dynamically. 
  * *Fix Applied:* Always pre-allocate `Float64Array` during initialization phase.
* **Sandbox Bypasses:** Do not attempt to use symlinks for file access. All read/write operations must resolve using realpath to prevent sandbox escapes.
* **HFT Queue Blocking:** `eprintln!` and standard I/O macros inside a lock-free queue completely destroy HFT latency. They block the async thread, leading to WS buffer bloat. Use atomic counters exclusively for drops.
* **Deserialization Fallbacks:** Using `unwrap_or(0.0)` for exchange stream data parsing can silently poison Limit Order Books (e.g. causing a 0.0 price to skew spread/OBI). Always cleanly `break`/`continue` or emit errors for bad data.
